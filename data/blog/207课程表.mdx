题目：

你这个学期必须选修 numCourses 门课程，记为 0 到 numCourses - 1 。

在选修某些课程之前需要一些先修课程。先修课程按数组 prerequisites 给出，其中 prerequisites[i] = [ai, bi] ，表示如果要学习课程 ai 则 必须 先学习课程 bi 。

例如，先修课程对 [0, 1] 表示：想要学习课程 0 ，你需要先完成课程 1 。

请你判断是否可能完成所有课程的学习？如果可以，返回 true ；否则，返回 false 。

## 入度

入度指的是指向某个顶点的边的数量。

我们可以把课程关系看成一张图：先修课指向想学的课。一门课的入度，就是它还有几门先修课没学。

思路是从入度为 0 的课（不需要先修课的课）出发，学完就把它删掉，同时让它指向的课入度减一；某门课入度降到 0，说明它的先修课都学完了，也可以学了。重复这个过程，最后如果还有课的入度不为 0，说明这些课的先修课形成了环，永远学不完。

以下面这个例子为例：

```js
输入：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1]]
输出：true
解释：学习课程 1 和 2 之前需要先完成课程 0，学习课程 3 之前需要先完成课程 1。
可以按 0 → 1 → 2 → 3 的顺序学完。
```

我们能得到图 ![课程依赖关系](/static/images/207课程表/course-graph.svg)

先建图：`const g = Array.from({ length: numCourses }, () => []);`，再准备一个入度数组 `const inDeg = new Array(numCourses).fill(0);`。

遍历每个 `prerequisites`，执行 `g[bi].push(ai)`，表示 bi 指向 ai，`g[bi]` 存的就是学完 bi 后可以解锁的课；同时 `inDeg[ai]++` 统计入度。

然后用队列 q 存所有入度为 0 的顶点。遍历 q，取出一个顶点 `node`，对它指向的每门课 `x`（即 `g[node]` 中的元素）执行 `inDeg[x]--`；如果 `inDeg[x] === 0`，就把 `x` 加进 q。

最后判断 `q.length === numCourses`：所有课都进过队列，说明都能学完，返回 true；否则说明存在环，返回 false。

以上面的例子走一遍：一开始只有 0 的入度为 0，q = [0]；取出 0，1 和 2 的入度变为 0，入队；取出 1，3 的入度变为 0，入队；取出 2、3，没有新的课。最终 q = [0, 1, 2, 3]，长度等于 4，返回 true。

```js
/**
 * @param {number} numCourses
 * @param {number[][]} prerequisites
 * @return {boolean}
 */
var canFinish = function (numCourses, prerequisites) {
  const g = Array.from({ length: numCourses }, () => [])
  const inDe = new Array(numCourses).fill(0)
  for (const [a, b] of prerequisites) {
    g[b].push(a)
    inDe[a]++
  }
  const q = []
  for (let i = 0; i < inDe.length; i++) {
    if (inDe[i] === 0) q.push(i)
  }

  let head = 0
  while (head < q.length) {
    const startNode = q[head++]
    for (const item of g[startNode]) {
      inDe[item]--
      if (inDe[item] === 0) {
        q.push(item)
      }
    }
  }
  return q.length === numCourses
}
```
