# 发展阶段

1. grunt, gulp, 繁琐的任务自动化 task
2. webpack 模块化打包构建的先驱 （rollup, parcel）
3. vite, bundleless 方案，借助于浏览器原生 esm 支持
   1. 开发环境 esbuild (快速启动)
   2. 生产环境 rollup （生态繁荣、配置化更高）
4. 字节：RsBuild -> rspack -> rslib -> rspress
   分支： oxc -> (oxc parser 、 oxc minifier、oxc resolver)-> rolldown + Vite
