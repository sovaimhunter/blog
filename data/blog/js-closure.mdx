## 什么是闭包

闭包让函数可以访问定义时所在作用域里的变量，即使外层函数已经返回。

```js
function counter() {
  let n = 0
  return () => ++n
}

const next = counter()
next() // 1
next() // 2
```

## 常见用途

### 数据私有化

上面的 `n` 无法从外部直接修改，只能通过返回的函数访问。

### 函数工厂

```ts
const multiply = (x: number) => (y: number) => x * y
const double = multiply(2)
```

## `var` 与循环陷阱

用 `var` 声明的循环变量在所有回调间共享，改成 `let` 即可让每次迭代拥有独立绑定。

## 总结

闭包 = 函数 + 它能访问的外部变量。
